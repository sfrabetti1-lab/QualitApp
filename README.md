# QualitApp

Strumenti Operativi per la Semplificazione e Governance Documentale in Sanità.
Basato sull'opera "Scrivere la Qualità in Sanità" di Simone Frabetti.

## Avvio locale

pnpm install
pnpm dev

Apri http://localhost:3000
